# Francky's Hot Dog Hub

créer une application mobile pour Francky's, une société spécialisé dans le hot-dog et ses produits dérivés avec les spécifications suivantes ansi que les fonctionnalités que tu juges pertinentes: - affichage liste des produits Francky's

- permettre la commande via l'app mobile

- remplissage du numéro de téléphone par le client lors de la commande

- réception et validation des commandes en BO

- lors de la commande, ajouter le choix de récupérer ou se faire livrer

- si récupération lors de la commande, choisir l'emplacement de récupération (le charriot)

- dans le BO, permettre l'ajout de charriot Francky's avec son emplacement

- création de compte dans l'app pour le client, possibilité de créer un compte avec le compte google

- login et mot de passe pour l'admin dans le BO

- le client peut voir la localisation du charriot le plus proche

- utiliser l'Ariary (Ar) comme devise

- donne moi un accès admin pour faire les paramétrages dans le BO et pour vérifier les commandes

- change le texte "Localier le charriot" en "Localiser le charriot le plus proche de ma position", à noter qu'il faut que la localisation de l'utilisateur soit activer pour cette fonctionnalité

- dans le BO, permettre d'ajouter les produits
